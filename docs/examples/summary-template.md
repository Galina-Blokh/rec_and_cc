# Meeting summary

Copy this file, edit the sections, and set `summary.template` in config.toml to its path.
Text before the first `##` section (this paragraph) is ignored.

## Updates by person
For each person who gave an update: their name (or speaker label if no name is said), then one bullet per update. Use only what they said. Write NONE if there are no updates.

## Decisions
Each explicit decision, one bullet each: what was decided, who decided it, and the timestamp [HH:MM:SS]. Only decisions that were clearly stated; mark tentative ones as "(tentative)". Write NONE if there is none.

## Action items
One bullet per task: "- <owner>: <task> (deadline: <deadline or 'not stated'>) [HH:MM:SS]". Only owners and deadlines that were said; if the owner is unclear, write "owner unclear". Write NONE if there is no task.

## Unresolved questions
Questions or topics raised but not answered or decided, one bullet each, with who raised it if clear. Write NONE if there are none.

## Unclear transcription
Names, figures or passages that look mistranscribed or are ambiguous, one bullet each with the timestamp and the likely meaning if it is reasonably clear. Write NONE if there are none.

## Personal data
The kinds of personal information mentioned (for example family, health, money, contact details, or a PIN or password), one bullet per kind. Name the kind only, never the detail. Write NONE if there is none.
