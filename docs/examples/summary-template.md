# Meeting summary

Copy this file, edit the sections, and set `summary.template` in config.toml to its path.
Text before the first `##` section (this paragraph) is ignored.

## Decisions and outcomes
Each decision made or outcome agreed, one bullet each, with who decided it. Write NONE if there is none.

## Action items
One bullet per task: "- <who>: <task>", with the deadline if one is said. Write NONE if there is no task.

## Project updates
Progress, blockers and news about each project that was mentioned, one bullet per project. Write NONE if nothing was said.

## Topics for discussion
Points that were raised but not decided, one bullet each.

## Personal data
The kinds of personal information mentioned (for example family, health, money, contact details, or a PIN or password), one bullet per kind. Name the kind only, never the detail. Write NONE if there is none.
